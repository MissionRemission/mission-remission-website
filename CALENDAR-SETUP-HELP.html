📅 Google Calendar API Setup Guide

Your events page needs the Google Calendar API enabled. Follow these steps:

Step 1: Go to Google Cloud Console

Visit: https://console.cloud.google.com/

Make sure you're signed in with the Google account that has your calendar.

Step 2: Enable Google Calendar API

  1. In the left menu, click "APIs & Services" → "Library"
  2. Search for "Google Calendar API"
  3. Click on it and press "Enable"

Step 3: Update API Key Restrictions

  1. Go to "APIs & Services" → "Credentials"
  2. Find your API key: AIzaSyDrHGEOjkN9gikDRKPSF7UEYXKOFh9RiMA
  3. Click on it to edit
  4. Under "API restrictions", make sure BOTH are checked:
    • ✅ Google Drive API
    • ✅ Google Calendar API
  5. Click "Save"

Step 4: Make Sure Calendar is Public

  1. Go to Google Calendar
  2. Find your calendar in the left sidebar
  3. Click the three dots (⋮) next to it
  4. Select "Settings and sharing"
  5. Scroll to "Access permissions"
  6. Check ✅ "Make available to public"
  7. Click "OK" on the warning dialog

⚠️ Important Notes:

  • It may take 5-10 minutes after enabling the API for it to work
  • Try refreshing the events page after waiting a few minutes
  • Make sure you're using the same Google account for the API key and calendar

Step 5: Test the Connection

Once you've completed the steps above:

  1. Wait 5-10 minutes
  2. Open events.html in your browser
  3. You should see your upcoming events!
